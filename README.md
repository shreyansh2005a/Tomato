🍅 Tomato: Full-Stack Food Delivery Web Application

Welcome to Tomato, a modern and responsive food delivery platform developed using the MERN stack. Whether you're craving salads, rolls, desserts, noodles, or anything in between, Tomato has got you covered.

🚀 Features

User Panel: Seamless browsing and ordering experience.

Admin Panel: Manage products, orders, and users efficiently.

JWT Authentication: Secure login and session management.

Password Hashing: Protect user credentials using Bcrypt.

Stripe Payment Integration: Secure online payments.

Responsive Design: Optimized for both desktop and mobile devices.

Product Filtering: Easily find your favorite dishes.

Order Management: Track and manage customer orders.

Role-Based Access: Differentiate between user and admin functionalities.

🛠️ Technologies Used

Frontend: React.js, React Router

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JWT, Bcrypt


Install backend dependencies:

cd ../backend
npm install
